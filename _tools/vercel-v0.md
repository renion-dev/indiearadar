## What is v0?

v0 is Vercel's AI-powered UI generator. Describe what you want in plain English, and it generates production-ready React components using Tailwind CSS and shadcn/ui.

## Key Features

- **Text-to-UI** — Describe components, get React code instantly
- **Copy-paste workflow** — No lock-in, just copy the code into your project
- **shadcn/ui integration** — Components use the same design system as your app
- **Responsive by default** — Generated code works on mobile and desktop
