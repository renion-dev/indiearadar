## What is Cursor Crane?
Cursor Crane is an AI-powered navigation tool for macOS that allows you to control your system interface using natural language and keyboard shortcuts. It eliminates the need for constant trackpad usage by letting you trigger actions, move windows, and interact with UI elements at the speed of your typing.

## Key Features
- **Natural Language Commands:** Simply type what you want to do (e.g., "Open Spotify and move it to the right half of the screen") and watch the AI execute it.
- **Smart UI Mapping:** Automatically identifies buttons, menus, and clickable elements on your screen, allowing for precise interaction without mouse input.
- **Keyboard-First Workflow:** Designed to keep your hands on the home row, minimizing the "context switching" friction between typing and pointing.
- **Context-Aware Automation:** Learns your common workflows to suggest shortcuts and automate repetitive multi-step tasks.
