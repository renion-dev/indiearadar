## What is Replicate?

Replicate is an API platform that lets you run open-source machine learning models with one line of code. No GPU setup, no infrastructure management.

## Key Features

- **50,000+ models** — Image generation, video editing, text-to-speech, and more
- **One API** — Same interface for all models
- **Pay per second** — Only pay for compute time you actually use
- **Auto-scaling** — Handles traffic spikes without configuration
