# ADR-003

# Programmatic SEO Engine

Status: Accepted

## Context

The project currently generates:

- AI tools
- Blog posts
- Tags
- Categories

However, commercial landing pages are still created manually.

This limits long-term SEO growth.

## Decision

Introduce a Programmatic SEO Engine.

All SEO pages will be described declaratively.

The generator will transform structured definitions into Markdown pages.

## Consequences

Advantages

- Unlimited scalability
- One generator
- Zero manual page creation
- Consistent architecture

Trade-offs

- Initial implementation complexity
- Requires maintaining structured metadata
